audio: Remove ProcessDeviceChangeTime.Suspended histogram

Field data from Media.AudioOutputController.ProcessDeviceChangeTime2
confirmed that excluding intervals where the system was suspended
brings Windows audio device switch times (~99 ms) on par with
macOS (~42 ms). The .Suspended histogram only recorded the sleep
duration itself and is no longer needed.

OBSOLETE_HISTOGRAM[Media.AudioOutputController.ProcessDeviceChangeTime.Suspended]=Removed after confirming ProcessDeviceChangeTime2 is healthy and device changes during suspend do not need dedicated tracking.
