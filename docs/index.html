Fix autotest filter for parameterized tests

If you pass a full test name, Foo.MyTest to autotest, it will find the
test and run it. If the test is a parameterized test, this currently
fails unless the parameterized test has no prefix. This change fixes the
bug, so it will find the test in either case.
