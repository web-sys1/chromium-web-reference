Record user manual filtering behavior after ignoring a Multistep Filter suggestion.

This CL introduces the MultistepFilter.PostIgnoreFiltering histogram to
track user behavior after they ignore or dismiss a Multistep Filter
suggestion. Specifically, it records whether the user subsequently
manually applies the same filters, different filters, or does not filter
further on the same site.

To support this, MultistepFilterMetricsTracker now tracks ignored
impressions and evaluates manual filter extractions on subsequent
navigations.
