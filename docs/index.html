Reland "[Bedrock] Convert PinnedToolbarActionsContainer tests to browser tests (Part 1/2)"

This is a reland of commit 8024832f1cfa60ead8eea73517d16dd401e86f2d

Compared to the original CL, MetricsRecordedForPinnableActions is
temporarily disabled on ChromeOS with
MAYBE_MetricsRecordedForPinnableActions.
It will be fixed and re-enabled in a follow-up CL.

Original change's description:
> [Bedrock] Convert PinnedToolbarActionsContainer tests to browser tests
> (Part 1/2)
>
> PinnedToolbarActionsContainer and PinnedActionToolbarButton rely on
> desktop browser window, toolbar, and action coordinator
> infrastructure,
> making browser tests the appropriate test environment.
>
> This CL converts core pinning, layout, priority, and metrics tests from
> pinned_toolbar_actions_container_unittest.cc to browser tests in
> pinned_toolbar_actions_container_browsertest.cc as part of Project
> Bedrock.
>
> In MetricsRecordedForPinnableActions, the expected pinnable action
> count deduction is adjusted from -3 to -2 (and -3 on ChromeOS). In
> browser tests, desktop browser features (Lens Overlay and Contextual
> Tasks) are active and registered in the root action item, whereas
> SplitTab and the inactive History cluster alternate are omitted.
