ash: Add LOGIN_PRIMARY -> LOGGED_IN_NOT_ACTIVE as known shutdown transition

During browser tests (e.g. MisconfiguredUserTest, ArcAuthServiceTest) or
when sign-in is aborted/failed during online session restore, Chrome
terminates and sets is_chrome_terminating_ to true. Subsequent tasks
in UserSessionManager::DoBrowserLaunch() can still attempt to transition
from LOGIN_PRIMARY to LOGGED_IN_NOT_ACTIVE, triggering a fatal
DUMP_WILL_BE_CHECK in SessionControllerImpl::SetSessionInfo().

Add LOGIN_PRIMARY -> LOGGED_IN_NOT_ACTIVE to known_transition_during_shutdown
to prevent these crashes, similar to how OOBE -> LOGGED_IN_NOT_ACTIVE was
added in crrev.com/c/7876481.
