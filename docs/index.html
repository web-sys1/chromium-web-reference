Set INPUT_METHOD_NOT_NEEDED on focusable Fusebox popup

When opening the focusable popup window on phones/tablets during an
active typing session, the popup is set as the IME client, causing a
flicker at the bottom of the screen where the soft keyboard was.

This CL marks the popup with INPUT_METHOD_NOT_NEEDED which aligns with
its actual property and resolves the keyboard flicker issue.
