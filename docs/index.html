[TrustedVault] Migrate main logic to new StandaloneTrustedVaultStorage

Update the business logic in the backend and related classes to use the
new StandaloneTrustedVaultStorage (which supports multiple security
domains sharing certain recovery factor data).
Some storage oriented logic is moved out of the business logic classes
and into storage classes (e.g. clearing all data for a user, or cleaning
up users marked for deletion).

The interface is still implemented by
LegacyStandaloneTrustedVaultStorageAdapter, so no change is made on the
on-disk format or the behaviour of backend.

Also, the tests still use the legacy storage format and
LegacyStandaloneTrustedVaultStorageAdapter. This ensures that the
adapter receives even greater test coverage than its own unit test
provides currently.
The tests will be migrated to natively use the new storage format in a
future CL.
