Deflake ShellTest.OpenFileWithSpaceInExtension modal-dialog wall

OpenFileViaShell calls ShellExecuteEx with SEE_MASK_NOASYNC, which runs
synchronously. For a file with an unregistered extension ("test. txt")
the shell can pop a modal "Open With" dialog; on a headless bot that
dialog is never dismissed, so the call blocks forever and walls the
whole test process (observed as a test-launcher timeout on win11-arm64).

Run OpenFileViaShell on a detached, non-joinable thread so a blocking
dialog only wedges that abandoned thread. The existing sentinel check
(executed.txt must not exist) still catches the real regression. A
ThreadPool task can't be used because TaskEnvironment drains its workers
at teardown and would still wall the process.
