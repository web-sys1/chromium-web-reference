Refactor BaseUIManager friend classes to use base::PassKey

This CL replaces the remaining `friend class` declarations in
BaseUIManager with `base::PassKey` parameters to restrict access to
RemoveAllowlistUrlSet and RemoveAllowlistUrlSetThreatType. This allows
ChromePasswordProtectionService and SuspiciousSiteControllerAndroid
to cleanly access these methods without needing to be friends, and
improves encapsulation. SafeBrowsingUIManagerTest remains a friend
to maintain test isolation.
