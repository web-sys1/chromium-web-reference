[Bedrock] Remove chrome_test_path_utils.h transitive re-export

chrome_test_utils.h was re-exporting chrome_test_path_utils.h via
include as a compatibility shim introduced when the path utils were
extracted into their own target. Now that all 86 consumer files that use
the path functions have been updated to include chrome_test_path_utils.h
directly, the transitive re-export in chrome_test_utils.h can be
removed.

The chrome_test_path_utils dep remains in chrome_test_utils's
public_deps so that consumer targets can resolve the direct include
without needing to add an explicit BUILD dep.

Also add chrome_test_path_utils to test_support_ui_android's public_deps
so that android_browser_test.cc (which also uses the path functions) can
resolve the include on Android.
