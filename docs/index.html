net/disk_cache/sql: Move blobs to shared cache on copy completion

When copying cache entries to SqlSharedCache, invoke
SqlPersistentStore::MoveBlobsToSharedCache after all entry body chunks
have been written. This updates the store's resource metadata to point
to the shared cache database and deletes the blob records from the
store.

On successful completion of MoveBlobsToSharedCache, OnCopyEntryComplete
is called. If MoveBlobsToSharedCache fails, OnCopyEntryFailed cleans up
the partially created entry in the isolated database.

Also update SqlSharedCache unittests to verify that the store's
shared_cache_resource_id is set after CopyEntries, and add a test case
for handling MoveBlobsToSharedCache failures.
