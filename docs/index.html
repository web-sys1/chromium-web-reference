WebUI Toolbar: Simplify draggable item state handling

This CL simplifies the WebUI Toolbar state update handling by applying
updates immediately during drag and click interactions, instead of
deferring them.

- Removes pointerdown deferral logic completely, simplifying state
  tracking.
- Updates during drag are applied immediately, preserving the local
  index of the dragged item (placeholder) in the layout.
- If an update removes the dragged item, the drag is aborted
  immediately.
- Fixes DOM corruption during drag abort by temporarily excluding the
  aborted item from keyedStates in reconcileKeys and restoring it in the
  next cycle.
- Updates tests to verify immediate application of updates and selective
  drag abort on item removal.
