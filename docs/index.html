Sync: Simplify SyncServiceFactory::IsSyncAllowed()

SyncServiceFactory::IsSyncAllowed() checks that Sync isn't blocked by
one of two specific things: command-line flag, or enterprise policy.
(Which seems "moderately useful" at best, really.)

Before this CL, this method tried to avoid creating a SyncServiceImpl
instance if it wasn't created yet. That seems a bit pointless (the
instance will probably get created very soon anyway), and to achieve
this it had to duplicate some logic.

This CL simplifies the logic, by letting the SyncServiceImpl get created
if necessary.

Some tests depended on IsSyncAllowed() returning true, even though the
SyncService was null (due to ServiceIsNULLWhileTesting()). These are
updated to set up a TestSyncService now.

Note: The eventual goal is to get rid of IsSyncAllowed(). After this CL,
that will be straightforward (just tedious).
