[WebNN] Allow WebGPU accelerator library to load in renderers under CIG

Running the WebNN GPU path in the renderer requires preloading
libLiteRtWebGpuAccelerator.dll pre-sandbox. Because MLDrift is
closed-source, it cannot be statically linked into chrome.dll.
Furthermore, as a non-MS-signed binary, it is blocked by Code
Integrity Guard (CIG) in the renderer with error 577
(ERROR_INVALID_IMAGE_HASH).

This CL adds an AllowExtraDll() exception in PreSpawnChild() so
the sandbox broker permits loading the accelerator library in
sandboxed renderers.
