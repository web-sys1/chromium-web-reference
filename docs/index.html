ui::ForcedColorProfileStringToColorSpace: Remove ICC roundtrip

When computing the forced color profile for "color-spin-gamma24", we do
a gfx::ColorSpace -> gfx::ICCProfile -> gfx::ColorSpace round-trip in
order to preserve the expected precision of layout tests.

Sometime in the past, this need went away. Remove the round-trip.
