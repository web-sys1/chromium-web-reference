[agy][gl] fix ANGLE task hang during shutdown

When ANGLE tasks are posted to the ThreadPool during shutdown,
they might be skipped (SKIP_ON_SHUTDOWN). This can lead to
threads hanging while waiting for these tasks to complete (e.g.
in AsyncWaitableEvent::wait).

This CL adds a fallback to run the task synchronously on the
calling thread if posting fails.
