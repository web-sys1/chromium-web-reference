[fuchsia] Unsparse userdata, tune SMP, and robustify boot in run_cuttlefish

- Unsparse & expand super.img (+8GB) and userdata.img (+16GB) as sparse
  files to provide sufficient capacity for Fuchsia Fxfs mutable storage
  and Chrome APK installations.
- Reduce QEMU -smp from 8 to 6 so the 8-core host bot retains CPU bandwidth
  for ADB daemon and test runner orchestration.
- Set androidboot.force_normal_boot=1 and androidboot.apex_updatable=0 in
  bootargs to stabilize userdebug cold boot on Starnix.
- Clean up lingering QEMU/ADB processes and verify ADB, root restart,
  sys.boot_completed, and package manager readiness before starting tests.
