[layout] Remove LayoutObject::RecalcScrollableOverflow.

All scrollable-overflow calculations now to through the
ScrollableOverflowCalculator.

Have RecalcScrollableOverflow on LayoutObject was a relic from a
pre-LayoutNG engine.

Remove, and simplify all the scrollable-overflow recalc methods on
LayoutBox.

Additionally there are some small fixes ensuring the
ScrollableOverflowCalculator never gets called with a LayoutReplaced.

There should be no behaviour change.
