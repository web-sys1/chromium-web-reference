Add virtual keyboard geometry emulation

Device Mode needs to emulate virtual keyboard geometry and keyboard
inset values without opening the platform keyboard. Add
Emulation.setVirtualKeyboardGeometryOverride for the inspected frame,
keep the override across navigation, and clear it when emulation ends.
Apply it independently of overlaysContent so DevTools can preview the
geometry without mutating page state.
