ServiceWorker: Do not set timing_allow_passed for filtered subresource responses

ServiceWorkerSubresourceLoader::StartResponse sets `timing_allow_passed`
on the response head. This should only be set for same-origin (kBasic)
or synthetic (kDefault) responses, and not for filtered responses
(kCors, kOpaque, kOpaqueRedirect, etc.).
