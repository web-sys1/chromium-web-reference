Suppress web app header presubmit warnings about using predefined texts

This helps suppress the presubmit warning
(https://paste.googleplex.com/6283906318991360) that shows up whenever
SetTextColor() is called on a view. This is needed because the
WebAppHeaderLayoutCoordinator sets the text color at runtime based
on the theme color for the app, and the static text appearance that
the presubmit points to cannot be applied onto it.
