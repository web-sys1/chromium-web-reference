Free libusb cached devices on macOS USB unplug

This partially imports
https://github.com/libusb/libusb/commit/d26cc697ccaba5496b56903eac12dc2b5838af04,
taking only the darwin_deref_cached_device call added to
darwin_devices_detached.

The rest is not applicable here: upstream later widened the
active_contexts_lock scope in 26dab3d6 and added a libusb_unref_device
call in 733ffffe, which made usbi_get_device_by_session_id return a
reference. The version pinned here does not, so that call would
over-release the device. The new block is therefore placed before
active_contexts_lock is taken, keeping the two locks non-nested.
