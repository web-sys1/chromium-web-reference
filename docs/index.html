webview: Add Compose integration tests

Android UI is increasingly Compose-first. Because Compose layout and
view attachment lifecycles interact with Android Views differently than
traditional XML layouts, we really should have tests for this.

I fixed an issue recently around eviction in our synchronous rendering
pipeline that was unique to compose and this first test would have
caught that.

Nothing major here, just need to give us visibility to use compose from
third_party and needed to switch our test runner activity to
ComponentActivity because we need the AndroidX lifecycle tracking from
ViewTreeLifecycleOwner.
