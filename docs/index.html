[rustmojo] Add InterfaceEndpointClientAdapter for Rust/C++ interop

We need the ability to attach Rust associated endpoints to primary
pipes that live in C++, and in order to do that we need to be able
to convert between the Rust and C++ routing abstractions.

This CL adds `InterfaceEndpointClientAdapter`, which is a C++ class
that acts as an `InterfaceEndpointClient` but mimics the API of a
`MultiplexRouterHandle`. Its methods will be exposed to Rust so that
a Remote or Receiver can use it to send/receive messages, and to
register new associated endpoints on the same pipe.

The IECAdapter will be held inside an `AssociatedEndpointRustAdapter`,
which will be added to the codebase in a followup CL. That adapter
acts as something like a generic associated remote/receiver, which
can be used to create a `PendingAssociated*` in either Rust or C++
code.

Note that this CL does not yet hook the new code into the build system,
since it isn't used anywhere yet.
