[glic] Extract prewarming checks into dedicated utility module

Glic prewarming checks were previously embedded inside
GlicProfileManager, even though evaluating prewarming eligibility
depends only on Profile state, system memory, and network connectivity
rather than GlicProfileManager instance state.

This CL extracts prewarming eligibility logic into dedicated
glic_warming_checks.h and glic_warming_checks.cc utilities, modularizing
the checks into profile eligibility, device memory constraints, and
network connection checks. GlicKeyedService now invokes
ShouldPreloadForProfile directly.

Additionally, prewarming tests are extracted into
glic_warming_checks_browsertest.cc using GlicBrowserTest for cross-
platform compatibility, split into distinct test fixtures to avoid
redundant browser startup/teardown cycles.
