Remove kUseRelatedWebsiteSet switch

This change removes support for `--use-related-website-set` and
`--use-first-party-set` (`network::switches::kUseRelatedWebsiteSet`), as
well as the associated command-line parsing and loader pathways in
content/ and services/network.

Tests that previously relied on the command line switch to inject
Related Website Sets are migrated to use Component Updater's test helper
`FirstPartySetsComponentInstallerPolicy::WriteComponentForTesting`. The
Blink `first-party-sets` virtual test suite and its test
`third-party-cookie-blocking-first-party-set-enabled.js` are removed, as
content_shell does not support Component Updater.
