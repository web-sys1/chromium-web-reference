Fix canvas 2D stroke pruning of degenerate zero-length path segments

In the HTML canvas spec for tracing paths [1], step 2 is to prune all
zero-length line segments from the path. This CL adds an early return in
DrawPathInternal when the stroke path has a zero-size bounding rect.

This fixes the following tests in
external/wpt/html/canvas/offscreen/path-objects/:
- 2d.path.stroke.prune.arc.worker.html
- 2d.path.stroke.prune.curve.worker.html
- 2d.path.stroke.prune.line.worker.html

[1] https://html.spec.whatwg.org/multipage/canvas.html#trace-a-path
