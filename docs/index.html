[OTP] Integrate user data processing consent fetching for OTP

This CL introduces the ability to fetch user data processing consent
states within the One Time Token (OTP) service.

Specific changes:
* Plumbs `FetchUserDataProcessingConsent` through `OneTimeTokenService`
  down to `GmailOtpBackend`.
* Implements the fetching logic in `GmailOtpBackendImpl` using the
  `UserDataProcessingConsentFetcher` to query the backend.
* Handles concurrent consent fetch requests by queuing callbacks if a
  fetch is already in flight.
* Adds comprehensive unit tests covering success, network errors, auth
  errors, concurrent requests, and cases where the Gmail backend is
  unavailable.
