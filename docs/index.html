Add PDFTranslationCoordinator to determine if a PDF is translatable.

This CL introduces PDFTranslationCoordinator, a DocumentUserData class that orchestrates the PDF-specific translation lifecycle. It checks if a PDF is translatable by querying PDFDocumentHelper to verify that the document has meaningful text, does not contain JavaScript, and is not password-protected.

The new coordinator and its unit tests are guarded by the enable_pdf_translation build flag.
