[GestureNav] Hand the gesture back instead of restarting it

BackForwardTransitionAnimationManager requires a destination entry for
the direction a gesture navigates in, and CHECKs it.

Previously, when TabOnBackGestureHandler received an event that did not
match an active gesture (no gesture in progress, or an edge mismatch),
it cancelled and restarted the gesture using the event's direction
without verifying session history. On tabs with no forward history, this
caused GetIndexForGoForward() to return nullopt, crashing in
crbug.com/530682179. That restart was a stopgap from 2024
(https://crrev.com/c/5921004, https://crrev.com/c/5941357) whose
diagnostic telemetry was later removed.

To ensure session history is respected, this CL removes the automatic
native restart and delegates gesture ownership back to the caller when
an event mismatch occurs. By returning false when the handler cannot
drive the gesture, UI controllers drop their native reference and safely
fall back to their standard history navigation handling.
