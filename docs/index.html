[contextual_tasks] Add `is_set_by_server` flag to SetActiveModelMode

Update `SetActiveModelMode` in `searchbox.mojom` and its implementations
to accept a boolean parameter indicating whether the model mode was set
by the server. This aligns `SetActiveModelMode` with `SetActiveToolMode`
for improved state and metrics tracking. This way, the browser process
knows if the server set the model, and different metrics can be logged
for server-set models here: crrev.com/c/193079

Pass the `is_set_by_server` flag across call sites in C++ handlers and
TypeScript WebUI components.

Update tests.
