media: Disallow hardware-secure CDM off the record

On Windows, the browser-side MediaFoundation CDM plumbing lacked an
off-the-record check: the only Incognito enforcement was renderer-side
key-system filtering. A compromised renderer can bypass renderer-side
filtering and directly invoke media::mojom::InterfaceFactory::CreateCdm
on MediaInterfaceProxy in the browser process.

When this occurred in an off-the-record profile, the browser launched
the out-of-process MediaFoundationService utility process pointing to
the regular profile's MediaFoundationCdmStore directory. This leaked
the regular profile's distinctive identifier (origin_id) and client
token, and persisted DRM state to the regular profile directory,
violating Incognito privacy guarantees.

This CL adds an IsOffTheRecord() check in MediaInterfaceProxy::CreateCdm
for hardware-secure MediaFoundation CDMs. If the hosting BrowserContext
is off-the-record, CDM creation is rejected with kCdmNotSupported.
