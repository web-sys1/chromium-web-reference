[contextual-tasks] Propagate color scheme parameter to task WebUI URL

Copy the color scheme (`cs`) query parameter from the task's creation
URL to the WebUI host URL when constructing task URLs. Previously,
without this parameter, the WebUI theme did not match the target page
theme immediately upon loading, causing visual flickering.

Additionally, switch to `AppendOrReplaceQueryParameter` when setting the
`cs` parameter to prevent adding duplicate query keys.
