[Views] Preserve active anchor highlights in Button::OnBlur()

When Button::OnBlur() was called while the button was pressed or
hot-tracked, it unconditionally set the InkDrop target state to
InkDropState::HIDDEN, ignoring whether anchor highlights were active.
When a button is activated via keyboard (such as Space or Return), the
opened dialog steals focus immediately before key release, causing
Button::OnBlur() to execute in STATE_PRESSED and stomp the newly created
anchor highlight back to HIDDEN.

This CL updates Button::OnBlur() to check if anchor_count_ > 0 before
animating to HIDDEN, preserving the highlight just as VisibilityChanged,
OnDragDone, and SetState already do.

Also re-enables PwaInstallViewBrowserTest.IconHighlightUpdated and
updates it to verify the InkDrop ripple state via InkDropHostTestApi.
