[STTS] Dynamically populate target devices in Share Sheet

This change updates ActivityServiceMediator to query available sync
target devices and dynamically populate device-specific Send Tab to Self
actions in the top row of the iOS Share Sheet.

Each available target device is displayed as an individual action
formatted as [First Name] • [Device Model], enabling direct one-tap tab
sharing without requiring an intermediate target picker sheet.
