[loomnibox] Keep input single-line when navigating dropdown suggestions

When singleLineOnInlineAutocomplete is enabled, only user-typed input is
allowed to expand the searchbox into multiline mode. When navigating
through dropdown suggestions (via arrow keys or focusin), match previews
do not expand the input to multiline mode, avoiding layout shifts and
accidental dropdown suppression.
