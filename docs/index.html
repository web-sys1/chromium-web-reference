[STTS] Constrain bottom sheet buttons to safe area horizontally

In landscape orientation on notched devices, anchoring table view bottom
sheet action buttons causes layout conflicts with the
safe-area-constrained content. This results in truncated list items in
landscape orientation.

This change anchors the primary and secondary action buttons to the safe
area layout guide horizontally using inequality constraints. This
ensures button widths and table view widths respect safe area margins in
portrait orientation while remaining within container bounds and
properly centered across all orientations.
