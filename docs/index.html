[EVP] Deduplicate emails on profile startup

This CL adds DeduplicateEmailVerificationState, which runs during
profile startup in MigrateDeprecatedAutofillPrefs. It normalizes all
keys to lowercase, merges permissions (keeping allowed: true if any
entry was allowed, and retaining the newer timestamp and corresponding
issuer_site), and removes any corrupted non-dict entries.
