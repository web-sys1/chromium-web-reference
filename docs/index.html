Allow empty cursor theme name in GTK

When no cursor theme is set in GTK settings (common in standalone window
managers like fvwm), gtk-cursor-theme-name is empty or null.
SanitizeCursorThemeName and the GTK settings interceptor previously
treated empty cursor theme names as invalid and replaced them with
"Adwaita", causing oversized cursors to be loaded instead of falling
back to the standard X11 cursor font.

This change allows empty strings and nullptr for cursor theme names
in IsValidThemeName, preserving the unconfigured state while still
rejecting invalid or path-traversing theme names.
