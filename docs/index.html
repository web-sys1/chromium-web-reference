[RM Line Focus] Adjust setLineFocusStyle_ based on page content

Include a `computeHasContent` evaluation within the `setLineFocusStyle_`
method so the line focus style is only applied when the page has content
(i.e., when line focus is actually shown). This prevents applying the
style when line focus is turned on but hidden (due to no content).

The CL also adds new tests for evaluating the "no content" scenario.
