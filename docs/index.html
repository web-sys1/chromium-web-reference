Defer WebrtcEncodingInfoHandler if GPU encoder support is not known.

This change modifies WebrtcEncodingInfoHandler to check if GPU encoder support is known before querying for encoding info. If not known, it uses GpuVideoAcceleratorFactories::NotifyEncoderSupportKnown to defer the EncodingInfo call until the support information is available, preventing a blocking call. The constructors are made private, and test classes are added as friends.
